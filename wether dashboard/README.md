# Weather Dashboard

A static weather dashboard that uses async JavaScript, the Fetch API, and Open-Meteo REST endpoints to search cities and render live weather metrics.

## Run

Open `index.html` in a browser.

## Features

- City search via the Open-Meteo Geocoding API.
- Live weather data via the Open-Meteo Forecast API.
- Async/await request flow with network, HTTP, JSON parsing, empty-result, and malformed-payload handling.
- Dynamic rendering of nested JSON fields for current conditions, units, location matches, and daily forecasts.
